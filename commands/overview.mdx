## Global vs Server Commands

**Global commands** work everywhere — in your DMs with Moddy, in any server you share with Moddy, and even in servers that haven't added Moddy. They don't rely on any server configuration.

Examples: `/translate`, `/ping`, `/user`, `/roll`, `/mycases`, `/fix`

**Server commands** only work inside a server where Moddy is installed. They interact with server-specific data like cases, configuration, and modules.

Examples: `/config`, `/cases`, `/ban`, `/altguard verify`

## Two Conventions Worth Knowing

<AccordionGroup>
  <Accordion title="Replies are private by default">
    Most commands take an `incognito` option. Leave it blank and Moddy uses your saved preference from `/preferences` — which defaults to **private**, so nobody else sees your command output. Set `incognito:false` to post the reply visibly in the channel.

    The one deliberate exception is the **Transcribe** right-click menu, which is public by design so the whole channel can read a voice note.
  </Accordion>

  <Accordion title="Right-click menus don't appear in the / picker">
    Five of Moddy's features live in Discord's **Apps** context menu instead of the slash picker: **AI text tools**, **Translate**, **Transcribe**, **Save Message**, and **Get Emojis**. Right-click any message (or long-press on mobile) and hover **Apps** to find them. See [Modules & Menus](/commands/module-commands).
  </Accordion>
</AccordionGroup>

## Full Command List

| Command | What it does | Where |
| --- | --- | --- |
| `/ban` `/kick` `/mute` `/warn` | Sanction up to 10 members with a reason and evidence | Server |
| `/cases` | Browse and manage your server's moderation cases | Server |
| `/mycases` | Review your own moderation history | Anywhere |
| `/config` | Enable and configure Moddy's modules | Server |
| `/translate` | Translate text into 25 languages | Anywhere |
| `/fix` `/rephrase` `/summarize` | AI writing helpers | Anywhere |
| `/reminder-add` `/reminders` | Set and manage personal reminders | Anywhere |
| `/library` | Browse your saved messages | Anywhere |
| `/roll` | Roll a random number | Anywhere |
| `/preferences` | Your privacy default and timezone | Anywhere |
| `/subscription` | Your Moddy Max status | Anywhere |
| `/ping` `/moddy` | Bot latency, and general info about Moddy | Anywhere |
| `/user` `/avatar` `/banner` | Look up a Discord user's profile, avatar, or banner | Anywhere |
| `/invite` `/emoji` `/webhook` | Inspect an invite, a custom emoji, or a webhook | Anywhere |
| `/altguard verify` `/altguard unverify` | Override the AltGuard gate for a member | Server |
| `/interserver report` `/interserver info` | Report or look up a relayed message | Server |
| `/view-saved-roles` `/clear-saved-roles` | Manage stored roles for returning members | Server |

<Tip>
  All Moddy commands are slash commands. There are no prefix commands like `!warn` or `!ban` — every interaction starts with `/` or a right-click.
</Tip>
