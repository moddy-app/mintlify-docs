Moddy uses Discord slash commands exclusively. Type `/` in any Discord message box to see the full list of available commands and their options. Every command is self-documenting: Discord shows you each parameter, whether it's required or optional, and a short description before you even submit.

## Global vs Server Commands

Moddy's commands fall into two categories depending on where you can use them.

**Global commands** are available everywhere — in your DMs with Moddy, in any server you share with Moddy, and even in servers that haven't added Moddy. These are standalone tools that don't rely on any server-specific configuration.

Examples: `/translate`, `/ping`, `/avatar`, `/roll`

**Server commands** only work inside a server where Moddy has been installed and set up. These commands interact with server-specific data like moderation cases, configuration, and module settings.

Examples: `/config`, `/cases`
