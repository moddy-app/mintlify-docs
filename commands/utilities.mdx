Moddy's utility commands are globally available — you can use them in your DMs with Moddy, in any server you share with Moddy, or even in servers that haven't added Moddy. They're standalone tools designed to save you time without needing any server setup. Most take an optional `incognito` boolean to make the response visible only to you.

---

## `/ping`

Check Moddy's current response latency. Moddy replies with its round-trip latency in milliseconds, which is useful for diagnosing whether the bot is experiencing slowness.

This command has no parameters.

```text
/ping
```

---

## `/translate`

Translate text into another language. Moddy always auto-detects the source language — there's no option to override it.

<ParamField path="text" type="string" required>
  The text you want to translate.
</ParamField>

<ParamField path="to" type="string">
  The target language, picked from a fixed dropdown (English US/UK, French, German, Spanish, Italian, Portuguese, Portuguese BR, Dutch, Polish, Russian, Japanese, Chinese, Korean, Turkish, Swedish, Danish, Norwegian, Finnish, Greek, Czech, Romanian, Hungarian, Ukrainian, Bulgarian). If omitted, Moddy translates into your Discord client's own language.
</ParamField>

**Example usage:**

```text
/translate text:Bonjour tout le monde to:🇺🇸 English (US)
```

```text
/translate text:Hello, how are you?
```

<Tip>
  Right-click any message and use the **Translate** context menu entry to translate it without retyping the text.
</Tip>

## `/reminder-add`

Set a personal reminder. Moddy notifies you when the time is up.

<ParamField path="message" type="string" required>
  The reminder text. Up to 1,000 characters.
</ParamField>

<ParamField path="time" type="string" required>
  When to send the reminder — relative durations like `30m`, `2h`, `1d`, or natural phrasing like `tomorrow 3pm`.
</ParamField>

<ParamField path="send_here" type="boolean">
  Post the reminder in the current channel instead of DMing you. Defaults to `false`.
</ParamField>

**Example usage:**

```text
/reminder-add message:Check the server for new applications time:2h
```

```text
/reminder-add message:Announce the event winners time:1d send_here:true
```

<Tip>
  Reminders are delivered via DM by default. Make sure your Discord privacy settings allow DMs from Moddy, or use `send_here:true` instead.
</Tip>

## `/reminders`

View your pending reminders and cancel any you no longer need. You can have up to 50 active at once.

```text
/reminders
```

---

## `/roll`

Roll a random number, like a die.

<ParamField path="max" type="integer">
  The highest possible value. Defaults to `6` (a standard six-sided die); accepts up to `1000000`.
</ParamField>

**Example usage:**

```text
/roll
```

```text
/roll max:20
```

## `/fix`, `/rephrase`, `/summarize`

AI-powered text tools — fix spelling and grammar, rewrite in a different style, or condense to key points. See the [Text Tools guide](/utilities/text-tools#ai-text-tools) for the full option list (styles, lengths) and the shared context-menu entry point.

```text
/fix text:teh quikc brown fox
/rephrase text:Hey can u send that file style:professional
/summarize text:<a long paragraph> length:bullets
```
