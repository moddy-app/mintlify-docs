Moddy's moderation commands give your team a structured, auditable workflow. Every action — a warning, a mute, a ban — is recorded as a **case** with a unique 6-character reference code (e.g. `AB3XR7`), building a full timeline of sanctions, notes, and evidence.

All commands on this page are **guild-only** and reply **privately** by default.

---

## Applying Sanctions

`/ban`, `/kick`, `/mute`, and `/warn` all work the same way: the slash command picks a first target, then opens a form where you confirm everything before anything happens.

```discord
/ban user:@member
/kick user:@member
/mute user:@member
/warn user:@member
```

<ParamField path="user" type="member" required>
  The first member to sanction. You can add more inside the form.
</ParamField>

<ParamField path="incognito" type="boolean">
  Whether the confirmation is visible only to you. Defaults to your `/preferences` setting, or private.
</ParamField>

### Inside the form

| Field | Details |
| --- | --- |
| **Targets** | 1 to **10** members in a single action |
| **Reason** | Required, up to 1000 characters |
| **Duration** | `/ban` and `/mute` only — free text, up to 50 characters. Leave blank for permanent. |
| **Evidence** | Up to **10** file uploads, attached to the case |
| **Notify by DM** | On by default — the member receives the reason and evidence |

### What each one does

| Command | Discord permission | Effect |
| --- | --- | --- |
| `/ban` | **Ban Members** | Removes the member and blocks rejoining. Supports a duration for a temporary ban. |
| `/kick` | **Kick Members** | Removes the member; they can rejoin with a new invite. No duration. |
| `/mute` | **Moderate Members** | Applies a Discord timeout for the duration you set. |
| `/warn` | **Moderate Members** | Records a warning and optionally DMs the member. No Discord-side action. |

### Hierarchy protection

<Warning>
  Moddy refuses a sanction when the target is the **server owner**, when the target is **yourself**, when the target's highest role is **at or above your own** (unless you're the owner), or when the target's highest role is **at or above Moddy's**. Every target is re-checked when you submit the form, not just when you run the command.

  `/warn` is the one exception to the last rule — a warning is a record, not a Discord action, so Moddy's own role position doesn't matter.
</Warning>

## `/cases`

Browse every moderation case in the current server in an interactive panel.

<ParamField path="case" type="string">
  Optional. A 6-character case reference (e.g. `AB3XR7`) to jump straight to that case.
</ParamField>

```discord
/cases
/cases case:AB3XR7
```

Requires **Manage Messages** (or Administrator) — adjustable per role from **Server Settings → Integrations**. The reply is always private.

From the list screen, a **Filters** button narrows by status, sanction type, period, and member. Selecting a case opens its detail screen, where you can:

| Action | Permission needed |
| --- | --- |
| Add a sanction (warn, mute, ban) | **Timeout Members** for warn/mute, **Ban Members** for ban |
| Revoke an active sanction | Same as the sanction being revoked |
| Comment, edit the reason, close or reopen | Manage Messages |
| Attach evidence — a link, or a snapshotted message | Manage Messages |

## `/mycases`

View your own moderation cases across every server that uses Moddy. Read-only, available to everyone with no permission required, and it works in servers and in DMs.

<ParamField path="case" type="string">
  Optional. A reference code to open directly — only resolves cases that are actually yours.
</ParamField>

```discord
/mycases
```

<Info>
  If you received an AutoMod sanction and want to appeal it, use the appeal buttons in Moddy's DM to you — you don't need to contact a moderator directly.
</Info>

## Auto-Recorded Sanctions

Bans and timeouts applied directly through Discord — without touching Moddy at all — are picked up automatically and recorded as cases, using the audit log to capture the real moderator and reason. Unbanning or clearing a timeout revokes the matching sanction.

This requires Moddy to have the **View Audit Log** permission. Kicks are never recorded as cases.

<Note>
  `/mod case` and the other `/mod`, `/dev`, `/team`, and `/manage` commands are **Moddy staff-only**, available exclusively on Moddy's own official servers. They are not part of the toolkit for servers running Moddy.
</Note>
