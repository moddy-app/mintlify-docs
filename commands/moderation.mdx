Moddy's moderation commands give your team a structured, auditable workflow for handling rule-breaking. Every action — a warning, a mute, a ban — is recorded as a **case** with a unique 6-character reference code (e.g. `AB3XR7`). Each case builds a full timeline of sanctions, notes, and evidence so your team always has context.

<Note>
  Server-side case management in Moddy is a single command, `/cases` — an interactive panel, not a set of separate slash subcommands. Everything below (creating, viewing, sanctioning, revoking, commenting, closing) happens inside that one panel.
</Note>

---

## `/cases`

Browse every moderation case in the current server in an interactive panel. Requires the **Manage Messages** permission (or Administrator) by default — adjustable per role from **Server Settings → Integrations**.

<ParamField path="case" type="string">
  Optional. A 6-character case reference (e.g. `AB3XR7`) to jump straight to that case's detail screen.
</ParamField>

```text
/cases
/cases case:AB3XR7
```

From the list screen, a **Filters** button lets you narrow by status (open/closed), sanction type, period, and — in `/cases` — a specific member. Selecting any case opens its detail screen.

### Managing a case from the detail screen

Once a case is open, its action buttons let you:

| Action | What it does | Permission needed |
| --- | --- | --- |
| Add sanction | Start a warn, mute, or ban — opens (or appends to) a case for that member | **Timeout Members** for warn/mute, **Ban Members** for ban |
| Revoke sanction | Lift an active sanction before it expires | Same as the sanction being revoked |
| Comment | Add a public note visible to other moderators in `/cases` | Manage Messages |
| Edit reason | Update the reason recorded on the case | Manage Messages |
| Close / Reopen | Manually lock the case's status | Manage Messages |
| Add evidence | Attach a link or a snapshotted Discord message to the timeline | Manage Messages |

A brand-new case is opened the same way — add a sanction against a member with no open case, and Moddy creates the folder and the sanction together in one step.

## `/mycases`

View your own moderation cases across every server that uses Moddy. This command is read-only — it shows you the cases that exist against your account so you can understand sanctions and reference codes if you need to appeal.

<ParamField path="case" type="string">
  Optional. A 6-character case reference to jump straight to that case's detail screen (only resolves cases that are actually yours).
</ParamField>

```text
/mycases
/mycases case:AB3XR7
```

Available to all users, no moderator permissions required, and works in any server or in DMs with Moddy.

<Info>
  If you received an AutoMod sanction and want to appeal it, use the appeal buttons in Moddy's DM to you — you don't need to contact a moderator directly.
</Info>

## Auto-Recorded Sanctions

Bans and timeouts applied directly through Discord — without touching `/cases` at all — are picked up automatically and recorded as cases, using the audit log to capture the real moderator and reason. This requires Moddy to have the **View Audit Log** permission in your server. Kicks are never recorded as cases.
