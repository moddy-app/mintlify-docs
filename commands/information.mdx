Moddy's information commands let you pull up details about Discord users, invites, custom emojis, and webhooks without leaving Discord. All of these commands are globally available — you can use them in your DMs with Moddy, in any server that has Moddy, or even in servers where Moddy isn't installed. Every command below also takes an optional `incognito` boolean to make the response visible only to you.

---

## `/user`

Look up profile information for any Discord user.

<ParamField path="user" type="user" required>
  The Discord user to look up.
</ParamField>

**Returns:** username, display name, account creation date, avatar, and Discord badges.

**Example usage:**

```text
/user user:@username
```

---

## `/avatar`

Display a user's full-size avatar with a direct download link. Supports both static and animated avatars.

<ParamField path="user" type="user" required>
  The user whose avatar you want to view.
</ParamField>

**Example usage:**

```text
/avatar user:@username
```

---

## `/banner`

Display a user's full-size profile banner. If the user hasn't set a banner, Moddy will let you know.

<ParamField path="user" type="user" required>
  The user whose banner you want to view.
</ParamField>

**Example usage:**

```text
/banner user:@username
```

---

## `/invite`

Look up information about a Discord server invite without joining it. Useful for vetting invites before sharing them with your community.

<ParamField path="invite_code" type="string" required>
  A Discord invite link (e.g. `https://discord.gg/abc123`) or just the invite code (e.g. `abc123`).
</ParamField>

**Example usage:**

```text
/invite invite_code:https://discord.gg/abc123
```

```text
/invite invite_code:abc123
```

---

## `/emoji`

Inspect a custom Discord emoji to see where it's from and get a direct link to its image.

<ParamField path="emoji" type="string" required>
  A custom Discord emoji (e.g. `:custom_emoji:`). Only works with **custom** emojis, not built-in Unicode emoji.
</ParamField>

**Returns:** emoji name, emoji ID, creation date, and a direct image URL.

**Example usage:**

```text
/emoji emoji::custom_emoji:
```

<Tip>
  Right-click a message that uses several custom emojis and select **Get Emojis** from the Apps menu to list every one of them at once, instead of looking each up individually with `/emoji`.
</Tip>

<Note>
  Standard Unicode emoji (like 😄) are not supported by `/emoji`. It only works with custom server emoji.
</Note>

---

## `/webhook`

Inspect **and manage** a Discord webhook — not just look it up.

<ParamField path="webhook" type="string" required>
  The webhook's full URL, or its ID/token pair.
</ParamField>

**Returns:** webhook name, the channel it posts to, and the server it belongs to — plus action buttons to **send** a test message through it, **edit** its name/avatar, **refresh** its data, or **delete** it outright.

**Example usage:**

```text
/webhook webhook:https://discord.com/api/webhooks/000000000000/xxxxxxxxxxxx
```

<Warning>
  Treat webhook URLs as sensitive credentials — anyone with a webhook URL can post messages to that channel, and `/webhook` itself can delete or edit the webhook if you have the details. Avoid sharing them in public channels, and only run this command with URLs you trust.
</Warning>
