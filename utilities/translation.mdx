The `/translate` command lets you translate any text into your target language without leaving Discord. Moddy always auto-detects the source language — there's no way to override it — so you only ever pick where you want the result translated _to_. It's available globally, meaning you can use it in DMs or any server, no setup required.

## Usage

```text
/translate text: <text> [to] [incognito]
```

<ParamField path="text" type="string" required>
  The text you want to translate.
</ParamField>

<ParamField path="to" type="string">
  The target language, picked from a fixed dropdown list (see below). If you leave it out, Moddy translates into your Discord client's own language.
</ParamField>

<ParamField path="incognito" type="boolean">
  Whether the result is visible only to you. If left unset, Moddy uses your saved preference.
</ParamField>

## Supported Languages

`to` is a dropdown, not free text — pick from:

English (US), English (UK), French, German, Spanish, Italian, Portuguese, Portuguese (Brazil), Dutch, Polish, Russian, Japanese, Chinese, Korean, Turkish, Swedish, Danish, Norwegian, Finnish, Greek, Czech, Romanian, Hungarian, Ukrainian, and Bulgarian.

## Examples

```text
/translate text: Hello world to: 🇫🇷 Français
```

Translates "Hello world" into French → _Bonjour le monde_

```text
/translate text: Bonjour tout le monde to: 🇺🇸 English (US)
```

Translates the French phrase into English → _Hello everyone_

```text
/translate text: こんにちは
```

No `to` given — Moddy translates into whatever language your Discord client is set to.

## Where It Works

`/translate` is a **global command** — you can run it in any of the following places:

- **DMs with Moddy** — open a direct message with Moddy and type the command
- **Any server** — even servers where Moddy isn't installed as a bot
- **Your own server** — works the same way with no extra configuration needed

<Tip>
  Right-click a message and use the **Translate** context menu entry to translate it instantly, without typing the text into the slash command yourself.
</Tip>
