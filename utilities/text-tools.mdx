## OCR: Extract Text from Images

OCR (optical character recognition) lets you pull readable text out of an image posted in Discord — no external app needed.

To use it:

<Steps>
  <Step title="Find a message with an image">
    Locate any message in Discord that contains an image you want to extract text from.
  </Step>
  <Step title="Open the context menu">
    Right-click the message (or long-press on mobile) to open the message context menu.
  </Step>
  <Step title="Select Apps → Extract Text">
    Hover over **Apps** in the context menu, then click **Extract Text**.
  </Step>
  <Step title="Read the extracted text">
    Moddy replies with the extracted text in an ephemeral message — only you can see it.
  </Step>
</Steps>

<Note>
  The OCR reply is ephemeral, meaning it's visible only to you and disappears when you dismiss it. No one else in the channel will see the extracted content.
</Note>

## Timestamp Generator

Use `/timestamp` to generate a Discord timestamp that automatically displays in each viewer's local time zone. No more "what time is that for me?" questions in your announcements.

```
/timestamp 2026-06-01 20:00
```

Discord renders the output as a formatted, clickable timestamp — for example, **June 1, 2026 8:00 PM** — but each person who reads it sees the equivalent time in their own time zone.

<Tip>
  Always use `/timestamp` when announcing events, maintenance windows, or deadlines in your server. It eliminates time zone confusion instantly and keeps your community in sync no matter where members are located.
</Tip>

## Dice Roller

Roll dice for tabletop RPGs, mini-games, or any time you need a fair random result. The `/roll` command supports standard dice notation.

```
/roll
```
Rolls a single six-sided die (d6).

```
/roll 2d6
```
Rolls two six-sided dice and returns the total.

```
/roll 1d20+5
```
Rolls a twenty-sided die and adds 5 to the result — useful for D&D ability checks.

Moddy displays each individual die result alongside the total, so every roll is transparent and verifiable.
