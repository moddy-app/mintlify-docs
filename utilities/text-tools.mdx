Moddy packs several handy tools that go beyond simple commands — AI-assisted writing, voice message transcription, message bookmarking, and more. All of the commands below are global: they work in DMs with Moddy and in any server, even ones where Moddy isn't installed.

## AI Text Tools

```text
/timestamp 2026-06-01 20:00
```

<CardGroup cols={2}>
  <Card title="Fix" icon="spell-check">
    `/fix <text>` corrects spelling, grammar, punctuation, and accents — nothing else. The meaning and tone stay exactly as you wrote them.
  </Card>

  <Card title="Rephrase" icon="pen-nib">
    `/rephrase <text> [style]` rewrites your text in a different style while keeping the same meaning. Choose from Neutral, Professional, Formal, Friendly, Casual, or Concise.
  </Card>

  <Card title="Summarize" icon="align-left">
    `/summarize <text> [length]` condenses a text down to its key points. Choose Short, Medium (default), or Bullet points.
  </Card>
</CardGroup>

All three work with text in **any language** — Moddy detects the input language automatically and replies in the same one.

### Using AI Text Tools on Someone Else's Message

You don't have to copy-paste text into the slash command. Right-click (or long-press on mobile) any message, open **Apps**, and select **AI text tools** to open a pre-filled, ephemeral editor where you pick Fix, Rephrase, or Summarize — with the message's text already loaded in.

<Note>
  The context-menu result is ephemeral (only you can see it), while running `/fix`, `/rephrase`, or `/summarize` directly posts the result visibly in the channel.
</Note>

## Voice Transcription

Turn a Discord voice message — or any audio attachment — into readable text.

- **Anywhere:** right-click a voice message, open **Apps**, and select **Transcribe**. This works in servers, DMs, and anywhere Moddy is user-installed.
- **In servers with the module enabled:** a **Transcribe** button appears directly under voice messages, so any member can trigger it with one click.

The finished transcription is posted publicly in the channel — including the detected language and the audio's duration — so the whole conversation can read it, not just the person who requested it.

## Saving Messages

Right-click any message, open **Apps**, and select **Save Message** to bookmark it. Saved messages are private to you and stay accessible even if the original message is later deleted or the channel becomes unreachable — a quick way to keep track of something important without pinning it for the whole server.

## Extracting Emojis

Right-click a message that uses custom emojis, open **Apps**, and select **Get Emojis** to get a clean, browsable list of every custom emoji used in it — handy for finding the source of an emoji you want to steal for your own server.

## Dice Roller

Roll a random number for tabletop games, giveaways, or any time you need a fair random pick.

```text
/roll
```

```text
/roll
/roll max: 20
```

```text
/roll 2d6
```

```text
/roll 1d20+5
```

`/roll` with no options rolls a number between 1 and 6, like a standard die. Pass `max` to roll between 1 and any value up to 1,000,000 — for example, `max: 20` for a twenty-sided die.

<Tip>
  Use the `incognito` option if you'd rather see the result privately instead of posting it to the channel.
</Tip>
