Never lose track of an important task again. Moddy's `/reminder` command lets you set a personal reminder right inside Discord, and Moddy will send you a DM when the time arrives. Reminders are completely private — no one else in your server can see them — and the command works globally, so you can set one from anywhere.

## Setting a Reminder

```
/reminder <time> <message>
```

<ParamField path="time" type="string" required>
  When you want to be reminded. Moddy accepts relative durations and absolute dates:
  - Relative: `30m` (30 minutes), `2h` (2 hours), `1d` (1 day)
  - Natural language: `tomorrow`
  - Absolute dates: `2026-01-15`
</ParamField>

<ParamField path="message" type="string" required>
  A short note describing what you want to be reminded about.
</ParamField>

## Examples

```
/reminder time: 30m message: Check the oven
```

```
/reminder time: 2h message: Team meeting
```

```
/reminder time: 1d message: Review the moderation logs
```

## How You're Notified

When your reminder is due, Moddy sends you a **direct message** containing the reminder text you provided. Make sure your DM settings allow messages from Moddy — otherwise the notification won't get through.

<Tip>
  If you're not receiving reminder notifications, open your Discord **Privacy & Safety** settings and enable **"Allow direct messages from server members"** for a server that Moddy is in. Alternatively, you can open a DM with Moddy directly to ensure messages can come through.
</Tip>

## Managing Reminders

You can view and cancel your pending reminders at any time through Moddy's command interface. Run `/reminder` and follow the interactive prompts to see a list of your upcoming reminders and remove any you no longer need.

<Note>
  Reminders are personal and private. Other server members — including administrators and moderators — cannot see, browse, or manage your reminders.
</Note>
