Moddy includes a set of utility commands you can use anywhere — in your server or in DMs with Moddy. Whether you need to quickly translate a message, set a reminder, or generate a time-zone-aware timestamp for an event announcement, these tools are always within reach.

## Using Utilities

Most utility commands work **globally** — meaning you can run them in DMs with Moddy or in any server, even ones where Moddy isn't installed. You don't need to be a server admin or have any special permissions. Just open Discord, type the command, and go.

A small number of commands — like `/config`, `/cases`, and `/setup-welcome` — require Moddy to be present in the server and are intended for server administrators and moderators. The commands listed on this page are all available globally.

## Quick Reference

| Command | What it does |
|---|---|
| `/ping` | Check bot response time |
| `/translate` | Translate text to another language |
| `/reminder` | Set a personal reminder |
| `/roll` | Roll dice |
| `/timestamp` | Generate a Discord timestamp |
| `/avatar` | View a user's avatar |
| `/banner` | View a user's profile banner |
| `/user` | Look up a Discord user |
| `/invite` | Inspect a Discord invite link |
| `/emoji` | Inspect a custom emoji |
