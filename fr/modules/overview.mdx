Les modules sont des fonctionnalités optionnelles que vous pouvez activer serveur par serveur pour étendre ce que Moddy fait pour votre communauté. Chaque module est indépendant — vous choisissez ceux à activer, vous les configurez selon les besoins de votre serveur, et vous les désactivez à tout moment. Tous les paramètres des modules sont gérés via la commande `/config` directement dans Discord, ou depuis le tableau de bord web à [dashboard.moddy.app](https://dashboard.moddy.app).

## Activer un module

Vous pouvez activer et configurer n'importe quel module en quelques secondes sans quitter Discord.

<Steps>
  <Step title="Ouvrir le panneau de configuration">
    Tapez `/config` dans n'importe quel salon de votre serveur. Cela ouvre le panneau interactif de configuration serveur de Moddy.
  </Step>
  <Step title="Sélectionner le module">
    Choisissez dans le menu le module que vous souhaitez activer. Chaque module possède sa propre section de paramètres.
  </Step>
  <Step title="Configurer ses paramètres">
    Renseignez les détails requis — tels qu'un salon cible, le texte d'un message, ou l'action à effectuer. La page de chaque module couvre en détail ses options spécifiques.
  </Step>
  <Step title="Enregistrer vos modifications">
    Cliquez sur **Enregistrer** pour appliquer votre configuration. Le module s'activera immédiatement.
  </Step>
</Steps>

## Gérer les modules depuis le tableau de bord

Chaque module disponible via `/config` est également accessible depuis le tableau de bord web à [dashboard.moddy.app](https://dashboard.moddy.app). Le tableau de bord offre les mêmes options de configuration avec une interface pleine page, ce qui facilite la gestion des paramètres complexes comme plusieurs messages de bienvenue ou plusieurs flux de notifications sociales à la fois. Connectez-vous avec votre compte Discord et sélectionnez votre serveur pour commencer.

<Tip>
  Activer ou modifier les paramètres d'un module nécessite la permission **Gérer le serveur** dans le serveur Discord que vous configurez. Si `/config` ne fonctionne pas pour vous, vérifiez que votre rôle dispose de cette permission.
</Tip>
