Moddy comprend un ensemble de commandes utilitaires que vous pouvez utiliser partout — dans votre serveur ou en DM avec Moddy. Que vous ayez besoin de traduire rapidement un message, de définir un rappel, ou de générer un horodatage tenant compte des fuseaux horaires pour l'annonce d'un événement, ces outils sont toujours à portée de main.

<CardGroup cols={2}>
  <Card title="Traduction" icon="language" href="/utilities/translation">

  </Card>

  <Card title="Rappels" icon="bell" href="/utilities/reminders">
    Définissez des rappels personnels avec `/reminder-add` et Moddy vous enverra un DM (ou vous mentionnera dans le salon) le moment venu — aucune application tierce requise.
  </Card>

  <Card title="Outils de texte" icon="wand-magic-sparkles" href="/utilities/text-tools">
    Corrigez, reformulez et résumez du texte grâce à l'IA, transcrivez des messages vocaux, enregistrez des messages et extrayez les émojis de n'importe quel message.
  </Card>

  <Card title="Lanceur de dés" icon="dice" href="/utilities/text-tools#dice-roller">

  </Card>

## Utiliser les utilitaires

La plupart des commandes utilitaires fonctionnent **globalement** — ce qui signifie que vous pouvez les exécuter en DM avec Moddy ou sur n'importe quel serveur, même ceux où Moddy n'est pas installé. Vous n'avez pas besoin d'être administrateur du serveur ni de disposer de permissions particulières. Ouvrez simplement Discord, tapez la commande, et c'est parti.

Un petit nombre de commandes — comme `/config` et `/cases` — nécessitent que Moddy soit présent sur le serveur et sont destinées aux administrateurs et modérateurs du serveur. Les commandes listées sur cette page sont toutes disponibles globalement.

## Aide-mémoire

| Commande | Ce qu'elle fait |
| --- | --- |
| `/ping` | Vérifier le temps de réponse du bot |
| `/translate` | Traduire du texte dans une autre langue |
| `/fix` | Corriger l'orthographe et la grammaire avec l'IA |
| `/rephrase` | Réécrire du texte dans le style choisi avec l'IA |
| `/summarize` | Condenser un texte à ses points essentiels avec l'IA |
| `/reminder-add` | Définir un rappel personnel |
| `/reminders` | Consulter et gérer vos rappels en attente |
| `/roll` | Tirer un nombre aléatoire (par défaut : 1–6) |
| `/avatar` | Voir l'avatar d'un utilisateur |
| `/banner` | Voir la bannière de profil d'un utilisateur |
| `/user` | Rechercher un utilisateur Discord |
| `/invite` | Inspecter un lien d'invitation Discord |
| `/emoji` | Inspecter un émoji personnalisé |
