Moddy Max a volontairement un périmètre restreint : il améliore la **personnalisation du bot** et les **notifications sociales**. Tout le reste — cas de modération, AutoMod AI, messages de bienvenue, AltGuard, Inter-Server et toutes les commandes utilitaires — fonctionne à l'identique sur chaque serveur, gratuit ou premium.

## Comparatif des fonctionnalités

| Fonctionnalité | Gratuit | Moddy Max |
| --- | --- | --- |
| Serveurs avec fonctionnalités premium | 0 | Jusqu'à 5 |
| Personnalisation du bot — pseudonyme, avatar, bannière, bio | ✗ | ✓ |
| Personnalisation du bot — style du nom (police, effet, couleurs) | ✓ | ✓ |
| Notifications sociales — comptes par plateforme | 1 | 5 |
| Notifications sociales — sondage YouTube | toutes les 300 s (5 min) | toutes les 60 s (1 min) |
| Notifications sociales — sondage Twitch | toutes les 120 s (2 min) | toutes les 30 s |
| Notifications sociales — sondage RSS | toutes les 600 s (10 min) | toutes les 120 s (2 min) |
| Notifications sociales — sondage Bluesky | temps réel | temps réel |
| AutoMod AI | ✓ capacités complètes | ✓ capacités complètes (aucune différence) |
| Cas de modération | ✓ | ✓ |
| Messages de bienvenue — jusqu'à 5 salons | ✓ | ✓ |
| AltGuard, Inter-Server, toutes les commandes utilitaires | ✓ | ✓ |

<Note>
  Moddy Max ne modifie actuellement pas la vitesse, le quota ni la précision d'AutoMod AI — la modération automatique fonctionne exactement de la même façon quel que soit votre forfait. Si cela devait changer, cette page sera mise à jour en conséquence.
</Note>

## Personnalisation du bot

Avec Moddy Max, vous pouvez modifier le pseudonyme, l'avatar, la bannière et la bio de Moddy sur chacun de vos serveurs premium, ce qui donne au bot une apparence native aux couleurs de votre communauté. La personnalisation du style de nom (polices, effets, couleurs appliqués au nom par défaut) reste disponible gratuitement — Moddy Max débloque en plus une identité véritablement personnalisée : un pseudonyme, un avatar et une bannière entièrement différents.

## Notifications sociales

Moddy Max relève les deux limites qui comptent pour une configuration de suivi de contenu intensive : vous pouvez suivre **5 comptes par plateforme** au lieu d'1, et Moddy sonde YouTube, Twitch et RSS **nettement plus vite** — Bluesky est déjà en temps réel sur tous les forfaits, il n'y a donc rien à accélérer de ce côté. Consultez la [page du module Social Notifications](/modules/social-notifications) pour le détail complet.

<Note>
  Moddy s'améliore en permanence — si de nouvelles différences entre forfaits sont ajoutées, elles apparaîtront sur cette page et dans la [documentation du module](/modules/overview) qu'elles affectent. Pour tout ce qui n'est pas listé ci-dessus, considérez que le forfait gratuit et Moddy Max se comportent de manière identique.
</Note>
