Moddy Max tiene un alcance intencionadamente limitado: mejora la **personalización del bot** y las **notificaciones sociales**. Todo lo demás — casos de moderación, AutoMod AI, mensajes de bienvenida, AltGuard, Inter-Server y todos los comandos de utilidad — funciona de forma idéntica en todos los servidores, gratis o premium.

## Comparación de funciones

| Función | Gratis | Moddy Max |
| --- | --- | --- |
| Servidores con funciones premium | 0 | Hasta 5 |
| Personalización del bot — apodo, avatar, banner, biografía | ✗ | ✓ |
| Personalización del bot — estilo del nombre (fuente, efecto, colores) | ✓ | ✓ |
| Notificaciones sociales — cuentas por plataforma | 1 | 5 |
| Notificaciones sociales — sondeo de YouTube | cada 300s (5 min) | cada 60s (1 min) |
| Notificaciones sociales — sondeo de Twitch | cada 120s (2 min) | cada 30s |
| Notificaciones sociales — sondeo de RSS | cada 600s (10 min) | cada 120s (2 min) |
| Notificaciones sociales — sondeo de Bluesky | tiempo real | tiempo real |
| AutoMod AI | ✓ capacidad completa | ✓ capacidad completa (sin diferencia) |
| Casos de moderación | ✓ | ✓ |
| Mensajes de bienvenida — hasta 5 canales | ✓ | ✓ |
| AltGuard, Inter-Server, todos los comandos de utilidad | ✓ | ✓ |

<Note>
  Moddy Max no cambia actualmente la velocidad, cuota ni precisión de AutoMod AI — la moderación automática funciona exactamente igual independientemente de tu plan. Si eso cambia alguna vez, esta página se actualizará para reflejarlo.
</Note>

## Personalización del bot

Con Moddy Max, puedes cambiar el apodo, avatar, banner y biografía de Moddy en cada uno de tus servidores premium, haciendo que el bot se sienta nativo de la identidad de tu comunidad. La personalización del estilo del nombre (fuentes, efectos, colores aplicados al nombre por defecto) sigue estando disponible gratis — Moddy Max además desbloquea una identidad realmente personalizada: un apodo, avatar y banner completamente diferentes.

## Notificaciones sociales

Moddy Max aumenta los dos límites que importan para una configuración activa de seguimiento de contenido: puedes seguir **5 cuentas por plataforma** en lugar de 1, y Moddy sondea YouTube, Twitch y RSS **significativamente más rápido** — Bluesky ya es en tiempo real en todos los planes, así que no hay nada que acelerar allí. Consulta la [página del módulo Notificaciones sociales](/modules/social-notifications) para el desglose completo.

<Note>
  Moddy siempre está mejorando — si se añaden nuevas diferencias entre planes, aparecerán en esta página y en los [documentos del módulo](/modules/overview) al que afecten. Para cualquier cosa no listada arriba, asume que gratis y Moddy Max se comportan de forma idéntica.
</Note>
