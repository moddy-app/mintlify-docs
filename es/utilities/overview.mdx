Moddy incluye un conjunto de comandos de utilidad que puedes usar en cualquier sitio — en tu servidor o en DMs con Moddy. Ya sea que necesites traducir rápidamente un mensaje, poner un recordatorio o generar una marca de tiempo con zona horaria para anunciar un evento, estas herramientas siempre están al alcance.

<CardGroup cols={2}>
  <Card title="Traducción" icon="language" href="/utilities/translation">
    Traduce texto a cualquier idioma con `/translate`. Moddy detecta automáticamente el idioma de origen, así que puedes saltarte las conjeturas.
  </Card>

  <Card title="Recordatorios" icon="bell" href="/utilities/reminders">
    Pon recordatorios personales con `/reminder-add` y Moddy te enviará un DM (o te mencionará en el canal) cuando llegue el momento — no se necesita ninguna aplicación de terceros.
  </Card>

  <Card title="Herramientas de texto" icon="wand-magic-sparkles" href="/utilities/text-tools">
    Corrige, reescribe y resume texto con IA, transcribe mensajes de voz, guarda mensajes y extrae emojis de cualquier mensaje.
  </Card>

  <Card title="Tirador de dados" icon="dice" href="/utilities/text-tools#dice-roller">
    Tira un número aleatorio con `/roll` — por defecto un dado de 6 caras, o establece cualquier valor máximo hasta 1.000.000.
  </Card>

## Usar las utilidades

La mayoría de los comandos de utilidad funcionan **globalmente** — lo que significa que puedes ejecutarlos en DMs con Moddy o en cualquier servidor, incluso en aquellos donde Moddy no está instalado. No necesitas ser administrador del servidor ni tener ningún permiso especial. Solo abre Discord, escribe el comando y listo.

Un pequeño número de comandos — como `/config` y `/cases` — requieren que Moddy esté presente en el servidor y están pensados para administradores y moderadores del servidor. Los comandos listados en esta página están todos disponibles globalmente.

## Referencia rápida

| Comando | Qué hace |
| --- | --- |
| `/ping` | Comprobar el tiempo de respuesta del bot |
| `/translate` | Traducir texto a otro idioma |
| `/fix` | Corregir ortografía y gramática con IA |
| `/rephrase` | Reescribir texto en un estilo elegido con IA |
| `/summarize` | Condensar texto a sus puntos clave con IA |
| `/reminder-add` | Poner un recordatorio personal |
| `/reminders` | Ver y gestionar tus recordatorios pendientes |
| `/roll` | Tirar un número aleatorio (por defecto: 1–6) |
| `/avatar` | Ver el avatar de un usuario |
| `/banner` | Ver el banner de perfil de un usuario |
| `/user` | Consultar un usuario de Discord |
| `/invite` | Inspeccionar un enlace de invitación de Discord |
| `/emoji` | Inspeccionar un emoji personalizado |
