Moddy Max is intentionally narrow in scope: it enhances **bot customization** and **social notifications**. Everything else — moderation cases, AutoMod AI, welcome messages, AltGuard, Inter-Server, and all utility commands — runs identically on every server, free or premium.

## Feature Comparison

| Feature | Free | Moddy Max |
| --- | --- | --- |
| Servers with premium features | 0 | Up to 5 |
| Bot Customization — nickname, avatar, banner, bio | ✗ | ✓ |
| Bot Customization — name style (font, effect, colours) | ✓ | ✓ |
| Social Notifications — accounts per platform | 1 | 5 |
| Social Notifications — YouTube polling | every 300s (5 min) | every 60s (1 min) |
| Social Notifications — Twitch polling | every 120s (2 min) | every 30s |
| Social Notifications — RSS polling | every 600s (10 min) | every 120s (2 min) |
| Social Notifications — Bluesky polling | realtime | realtime |
| AutoMod AI | ✓ full capability | ✓ full capability (no difference) |
| Moderation Cases | ✓ | ✓ |
| Welcome Messages — up to 5 channels | ✓ | ✓ |
| AltGuard, Inter-Server, all utility commands | ✓ | ✓ |

<Note>
  Moddy Max does not currently change AutoMod AI's speed, quota, or accuracy — automatic moderation runs exactly the same regardless of your plan. If that ever changes, this page will be updated to reflect it.
</Note>

## Bot Customization

With Moddy Max, you can change Moddy's nickname, avatar, banner, and bio on each of your premium servers, making the bot feel native to your community's brand. The name-style customization (fonts, effects, colours applied to the default name) stays available for free — Moddy Max additionally unlocks a genuinely custom identity: a different nickname, avatar, and banner altogether.

## Social Notifications

Moddy Max raises both limits that matter for a busy content-tracking setup: you can follow **5 accounts per platform** instead of 1, and Moddy polls YouTube, Twitch, and RSS **significantly faster** — Bluesky is realtime on every plan already, so there's nothing to speed up there. See the [Social Notifications module page](/modules/social-notifications) for the full breakdown.

<Note>
  Moddy is always improving — if new plan differences are added, they'll show up on this page and in the [module docs](/modules/overview) they affect. For anything not listed above, assume free and Moddy Max behave identically.
</Note>
