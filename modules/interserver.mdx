Inter-Server lets you connect a channel in your server to channels in other Discord servers, so members from different communities can communicate with each other in real time. Whether you want to partner with another server, coordinate between branches of your community, or create a shared space with trusted allies, Inter-Server makes it possible without any external tools or integrations.

## How It Works

When a channel is part of a bridge network, any message sent in that channel is automatically relayed to all other channels connected to the same network. Members in each server see the messages as if they were posted locally. Each server's moderators retain full control over their own bridged channel — you can configure AutoMod, manage permissions, and remove relayed messages independently, without needing coordination from the other server's admins.

## Setting Up a Bridge

<Steps>
  <Step title="Open the configuration panel">
    Type `/config` in your server to open Moddy's configuration panel.
  </Step>
  <Step title="Select Inter-Server">
    Choose **Inter-Server** from the module list to open the bridging settings.
  </Step>
  <Step title="Choose a channel">
    Select the channel in your server that you want to connect to the bridge. Only messages sent in this channel will be relayed.
  </Step>
  <Step title="Create or join a network">
    To start a new bridge, create a new network — Moddy will generate a unique **network ID** for it. To join an existing bridge, enter the network ID shared with you by the other server's admin. Share your network ID with any other server admin who should be part of the same bridge.
  </Step>
  <Step title="Save your settings">
    Click **Save**. Your channel is now part of the bridge network and will relay messages to and from all other connected channels.
  </Step>
</Steps>

<Warning>
  Moddy needs the **Manage Webhooks** permission in the bridged channel — relayed messages are posted through a webhook so they can show the original author's name and avatar. Without it, saving the bridge for that channel will fail.
</Warning>

## Moderation in Bridged Channels

Relayed messages are posted through a **webhook** so they can carry the original author's name and avatar — which means they arrive from a different Discord account than the original sender. Server moderators can still delete a relayed message from their own channel at any time (this removes it locally, without affecting the other servers in the network), and the original message's own server moderates it normally at the source.

<Warning>
  Moddy's AutoMod AI does **not** scan relayed (webhook-posted) messages — it only evaluates messages sent directly by members, by design. If harmful content slips through a bridge, delete it locally and use `/interserver report` (below) so the Moddy team can look into it, or contact the source server's moderators directly.
</Warning>

<Warning>
  Bridging a channel exposes it to all members of every other server in the network. Only create or join bridges with communities you fully trust. Review the other server's rules and moderation practices before connecting.
</Warning>

<Note>
  Inter-Server is a built-in Moddy feature — it does not require any external bots, webhooks you manage yourself, or third-party services. Everything is handled automatically once you configure the bridge in `/config`.
</Note>

## Reporting an Abusive Message

If a relayed message violates Discord's Terms of Service or Moddy's own rules and needs the Moddy team's attention (rather than just your own server's moderation), any member can report it directly:

```discord
/interserver report <message_id>
```

`<message_id>` accepts either the relayed message's Discord snowflake ID or its Moddy ID — a short, unique 8-character code Moddy attaches to every relayed message so it can be tracked across every server in the network. The report is sent straight to the Moddy team for review, independently of whatever action your own moderators take locally.
