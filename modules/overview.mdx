Modules are optional features you can activate on a per-server basis to extend what Moddy does for your community. Each module is independent — you choose which ones to enable, configure them to fit your server's needs, and turn them off at any time. All module settings are managed through the `/config` command directly in Discord, or from the web dashboard at [dashboard.moddy.app](https://dashboard.moddy.app).

## Enabling a Module

You can enable and configure any module in seconds without leaving Discord.

<Steps>
  <Step title="Open the configuration panel">
    Type `/config` in any channel in your server. This opens Moddy's interactive server configuration panel.
  </Step>
  <Step title="Select the module">
    Choose the module you want to enable from the menu. Each module has its own settings section.
  </Step>
  <Step title="Configure its settings">
    Fill in the required details — such as a target channel, message text, or action to take. Each module's page covers its specific options in detail.
  </Step>
  <Step title="Save your changes">
    Click **Save** to apply your configuration. The module will activate immediately.
  </Step>
</Steps>

## Managing a Module

Once a module is configured, a small **Manage** button appears at the bottom of its home screen in `/config`. It opens one panel, the same for every module, where you can:

- **Change its state.** **Active** — the module works normally. **Paused** — it stops acting and its commands are hidden. **Simulation** — available for [AutoMod](/moderation/automod) only: it watches and announces what it would do, without applying anything.
- **Delete its configuration.** After a confirmation, every setting of the module is erased on your server and the module stops. This is available for Adaptive Slowmode, AltGuard, Auto Role, Auto-Restore Roles, AutoMod, Inter-Server, Server Logs, Member Applications, Starboard and Voice Transcription.

Pausing keeps your settings, so resuming is one click away.

<Note>
  Most modules are off until you configure them. A few, such as [AI Detector](/modules/ai-detector), are **on by default**: they work in every server with sensible defaults until you pause or adjust them.
</Note>

## Permissions Moddy Needs

Moddy never needs the **Administrator** permission. Each module asks only for what it actually uses, and `/config` checks it when you open that module: if something is missing, the panel lists **everything** that is missing at once — server permissions and permissions on the channels you picked — and gives you a re-invite link that requests exactly those permissions.

| Module | Permissions Moddy needs |
| --- | --- |
| Welcome, Welcome DM, Starboard, Social Notifications, Voice Transcription, Bump Reminder, AI Detector | Nothing beyond seeing and sending messages in the channels you pick |
| Auto Role, Auto-Restore Roles, AltGuard | Manage Roles |
| Member Applications | Kick Members |
| Adaptive Slowmode | Manage Channels |
| Tickets | Manage Channels, Manage Roles |
| Server Logs, Inter-Server | Manage Webhooks |
| Bot Customization | Change Nickname |
| AutoMod | Manage Messages, Ban Members, Timeout Members, Manage Nicknames, Attach Files |

<Note>
  For modules that hand out roles, Moddy's own role must also sit **above** the roles it manages in your server's role list — Discord's rule, not Moddy's.
</Note>

## Managing Modules from the Dashboard

Every module available via `/config` is also accessible from the web dashboard at [dashboard.moddy.app](https://dashboard.moddy.app). The dashboard provides the same configuration options with a full-page interface, making it easier to manage complex settings like multiple welcome messages or several social notification feeds at once. Log in with your Discord account and select your server to get started.

<Tip>
  Enabling or editing module settings requires the **Manage Server** permission in the Discord server you're configuring. If you don't see `/config` working, check that your role has this permission.
</Tip>
